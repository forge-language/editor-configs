# Forge editor configurations

Vim and Neovim file detection, syntax and language server integration for Forge `.fg` files. Install the `vim/` or `nvim/` subdirectory using its [Vim](vim/README.md) or [Neovim](nvim/README.md) instructions. The language server is maintained separately in [forge-lsp](https://github.com/forge-language/language-server).
