# Forge editor configurations

Vim and Neovim file detection, syntax and language server integration for Forge `.fg` files. Install the `vim/` or `nvim/` subdirectory using its [Vim](vim/README.md) or [Neovim](nvim/README.md) instructions. The language server is maintained separately in [forge-lsp](https://github.com/forge-language/language-server).

Apache 2.0; see [LICENSE](LICENSE) and [PROVENANCE.md](PROVENANCE.md).

Sublime Text support is maintained in the independent
[Forge syntax package](https://github.com/forge-language/sublime-syntax)
for highlighting, snippets and build commands, and the optional
[LSP-Forge package](https://github.com/forge-language/sublime-text)
for language-server integration. Syntax support works without LSP.
See each package's README and GitHub Releases for installation.
